## Create a key

<Steps>
  <Step title="Sign in to FormBharo">
    Go to [formbharo.artpark.ai](https://formbharo.artpark.ai) and sign in.
  </Step>
  <Step title="Open API keys">
    Click your profile picture in the top right, then **API keys**. This opens your workspace, where the keys live. Any member of a workspace can create one.
  </Step>
  <Step title="Create it">
    Click **Create API key**, enter a name, then **Create key**.
  </Step>
  <Step title="Copy it now">
    The key is shown once. Copy it and store it somewhere safe.

    <Warning>
      You cannot view the full key again after closing the dialog. If you lose it, revoke it and create a new one.
    </Warning>
  </Step>
</Steps>

Keys start with `fb_live_`.

## Use it

Send the key as a bearer token on every request.

```bash
curl "https://api.formbharo.artpark.ai/api/v1/agents" \
  -H "Authorization: Bearer $FORMBHARO_KEY"
```

A list of your agents, or `[]` if you have none, means the key works.

## What a key can do

A key reaches the agents in its workspace and acts with the role you hold there. It cannot create or revoke other keys.

## Revoke a key

Find the key by name in the same **API keys** table and click **Revoke**. The next request using it gets `401`.

<Note>
  Never commit a key to source control or embed it in client-side JavaScript. Use environment variables or your team's secret manager.
</Note>
