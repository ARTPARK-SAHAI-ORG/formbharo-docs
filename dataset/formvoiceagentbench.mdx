FormVoiceAgentBench is a Hindi benchmark built on a maternal and child health enrollment form. It pairs 380 audio recordings with multi-turn conversation tests drawn from 960 simulated calls. It was released with the paper [FormBharo: Designing and Evaluating a Voice Agent for Conversational Form Filling in Rural India](https://arxiv.org/abs/2608.06027).

## What it tests

The benchmark tests the speech-to-text model and the two LLMs inside the agent.

| Benchmark      | What it tests                                                                            |
| -------------- | ---------------------------------------------------------------------------------------- |
| Speech-to-text | Transcribing the caller's speech                                                         |
| EXTRACT        | Pulling the form values out of the transcribed text, and writing a short acknowledgement |
| REPLY          | Asking the next question, or ending the call once the form is complete                   |

## Download the dataset

Each benchmark is published on [Calibrate](https://docs.calibrate.artpark.ai/cli/overview), the open-source package used to run these evaluations. Open a benchmark and click **Export results** to download it.

| Benchmark      | Link                                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------------------- |
| Speech-to-text | [Speech-to-text benchmark](https://calibrate.artpark.ai/public/stt/9d25da9f-2727-42ee-931d-422858017383)        |
| EXTRACT        | [Data extraction accuracy benchmark](https://calibrate.artpark.ai/public/benchmark/4431ba9d-0ca2-457b-b924-e194d5414b1c) |
| REPLY          | [Response quality benchmark](https://calibrate.artpark.ai/public/benchmark/a508373f-1ee9-486c-90e3-214abd567d8f) |

| Benchmark      | What you get                                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Speech-to-text | A zip file with every recording in `audios/`, and `results.csv` with each model's transcript next to the reference transcript, with its scores |
| EXTRACT        | A CSV file with one row per model per test case: the conversation so far, the model's output, whether it passed, and each judge's verdict |
| REPLY          | A CSV file with one row per model per test case: the conversation so far, the model's reply, whether it passed, and each judge's verdict  |

### Speech-to-text

380 recordings, each with a reference transcript. Each model's transcripts are scored against the reference on word error rate, character error rate, and three LLM judges.

### EXTRACT

1880 test cases. Each one is a single turn of a call, with the conversation so far. The caller's messages are ElevenLabs Scribe v2 transcripts, recorded under four acoustic conditions.

Each case checks that the model calls the `process_user_turn` tool with the right values. An LLM judge grades the values, since a spoken name or place has many valid spellings.

### REPLY

1880 test cases. 920 check a spoken reply. 960 check that the model calls the `end_call` tool once the form is complete.

A reply has many correct phrasings, so LLM judges grade it instead of an exact match. A reply passes only if every judge listed for it passes.

| Judge                    | Applies to             | Checks                                                                                   |
| ------------------------ | ---------------------- | ---------------------------------------------------------------------------------------- |
| Correctness              | Every reply            | The reply asks the question the form selected next                                       |
| Script Fidelity          | Every reply            | The question is spoken word for word, as written in the form                             |
| No Acknowledgement       | Every reply            | The reply does not acknowledge the caller's previous answer                              |
| No Value Echo            | Every reply            | The reply does not read back the value the caller just gave                              |
| Hindi Language adherence | Every reply            | The reply is in Hindi, written in Devanagari                                             |
| Reply Conciseness        | Every reply            | The reply is exactly one question, with no bundled questions, summaries, or small talk   |
| Info Script              | 520 of the 920 replies | The required informational line is spoken word for word, once, right before the question |
