import { FORMBHARO_URL } from "/snippets/formbharo-url.mdx";

`POST /offer` and `GET /api/v1/data/{agent_id}/{conversation_id}` are the two routes you call without an API key. Every other route needs one.

## Before you start

You need the **agent ID** of the agent you want to run and the **URL of your FormBharo server**.

`GET /api/v1/agents/{agent_id}/public` returns the agent's `title`, `questions` list, and `agent_speaks_first` flag. Use it to render your form UI before the audio connection opens. It needs no API key.

```bash curl
curl {FORMBHARO_URL}/api/v1/agents/AGENT_ID/public
```

`agent_speaks_first` tells you whether to show a "waiting for agent" state or a push-to-talk prompt on connect.

## Run the call

<Steps>

  <Step title="Generate a conversation ID">
    FormBharo uses the ID you provide. It does not generate one for you.

    ```javascript javascript
    const conversationId = crypto.randomUUID();
    ```

    You pass this to the WebRTC offer and use it later to poll for answers.
  </Step>

  <Step title="Open the audio connection">
    `POST /offer` starts the WebRTC handshake. This path sits at the bare root of the server, not under `/api/v1`.

    Send a JSON body with these fields:

    | Field | Value |
    |---|---|
    | `sdp` | Your browser's WebRTC SDP offer string |
    | `type` | Always `"offer"` |
    | `request_data` | Object with `agentId` and `conversation_id` |

    The response is a WebRTC SDP answer. To exchange ICE candidates after the initial handshake, send them with `PATCH /offer`.

    ```javascript javascript
    const conversationId = crypto.randomUUID();

    const pc = new RTCPeerConnection();

    pc.addTransceiver("audio", { direction: "sendrecv" });

    await pc.setLocalDescription(await pc.createOffer());

    // Wait for ICE gathering to complete
    await new Promise((resolve) => {
      if (pc.iceGatheringState === "complete") {
        resolve();
      } else {
        pc.addEventListener("icegatheringstatechange", () => {
          if (pc.iceGatheringState === "complete") resolve();
        });
      }
    });

    const offerResponse = await fetch(
      "{FORMBHARO_URL}/offer",
      {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          sdp: pc.localDescription.sdp,
          type: "offer",
          request_data: {
            agentId: "AGENT_ID",
            conversation_id: conversationId,
          },
        }),
      }
    );

    const answer = await offerResponse.json();

    await pc.setRemoteDescription(new RTCSessionDescription(answer));

    // Play incoming audio
    pc.addEventListener("track", (event) => {
      const audio = new Audio();
      audio.srcObject = event.streams[0];
      audio.play();
    });
    ```
  </Step>

  <Step title="Read answers as they arrive">
    Poll `GET /api/v1/data/{agent_id}/{conversation_id}` every two seconds or so.

    - Before the first answer is written, it returns an empty object `{}`.
    - Once the call is underway, it returns a `form_data` object keyed by question ID and a `form_status` string.

    ```javascript javascript
    async function pollAnswers(agentId, conversationId) {
      const url = `{FORMBHARO_URL}/api/v1/data/${agentId}/${conversationId}`;

      const interval = setInterval(async () => {
        const res = await fetch(url);
        const data = await res.json();

        if (data.form_status === "complete" || data.form_status === "screened_out") {
          clearInterval(interval);
        }

        console.log("Current answers:", data.form_data);
      }, 2000);
    }
    ```
  </Step>

</Steps>
