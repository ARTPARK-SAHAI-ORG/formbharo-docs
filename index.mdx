FormBharo runs AI voice agents that ask your form questions out loud, listen to the answers, and save them — no typing required from the person on the other end. There are two main ways to use it: build your own page that starts calls and shows answers arriving in real time, or pull finished calls into your own systems once a conversation is complete.

## How it works

<Steps>
  <Step title="Build your agent">
    Define the questions you want answered, choose their response types, and write the script the agent uses to introduce itself. Each agent is a self-contained form plus the rules that govern how the agent asks it.
  </Step>
  <Step title="Start a call">
    Embed the WebRTC interface on your own page so visitors can start a call in their browser, or trigger outbound calls directly via the API. The agent takes it from there.
  </Step>
  <Step title="Collect the answers">
    Poll the API after the call ends or read answers in real time as the conversation happens. Every response is stored against the conversation and ready to pull into your system.
  </Step>
</Steps>
