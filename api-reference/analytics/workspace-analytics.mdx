`GET /api/v1/workspaces/{workspace_id}/analytics` returns the same statistics as the agent analytics endpoint, but aggregated across all agents in a workspace. It also includes a per-agent breakdown. Only workspace admins can call this endpoint.

## Authentication

Required. The API key must belong to a workspace admin. Workspace members receive a `403 Forbidden` response.

```http
Authorization: Bearer <api-key>
```

## Path Parameters

<ParamField path="workspace_id" type="string" required>
  The unique identifier of the workspace to retrieve analytics for.
</ParamField>

## Query Parameters

<ParamField query="status" type="string">
  Restrict the calculation to conversations with this status. One of `in_progress`, `complete`, `screened_out`, or `failed`.
</ParamField>

<ParamField query="source" type="string">
  Restrict the calculation to conversations from a specific call source.
</ParamField>

<ParamField query="since" type="number">
  Unix timestamp lower bound on `created_at` (inclusive).
</ParamField>

<ParamField query="until" type="number">
  Unix timestamp upper bound on `created_at` (inclusive).
</ParamField>

## Response

The response is a WorkspaceAnalytics object. The top-level fields are identical to the [Agent Analytics](/api-reference/analytics/agent-analytics) response, aggregated across every agent in the workspace. An additional `agents` array provides the same breakdown per agent.

<ResponseField name="attempted" type="integer">
  Total calls started across all agents in the workspace.
</ResponseField>

<ResponseField name="completed" type="integer">
  Calls with status `complete` or `screened_out` across all agents.
</ResponseField>

<ResponseField name="screened_out" type="integer">
  Calls screened out before completing the full form, across all agents.
</ResponseField>

<ResponseField name="completion_rate" type="number">
  Workspace-wide ratio of `completed` to `attempted`.
</ResponseField>

<ResponseField name="avg_duration_secs" type="object">
  Workspace-wide average call duration. Shape: `{ value, ci95, sample_count }`. `null` when there are no usable calls; `ci95` is `null` when fewer than 2 calls are available.
</ResponseField>

<ResponseField name="avg_ack_latency_secs" type="object">
  Workspace-wide average acknowledgement latency. Same shape as `avg_duration_secs`.
</ResponseField>

<ResponseField name="avg_ack_to_reply_secs" type="object">
  Workspace-wide average time from agent acknowledgement to contact reply. Same shape as `avg_duration_secs`.
</ResponseField>

<ResponseField name="cost" type="object">
  Workspace-wide cost breakdown. Shape: `{ call_count, total, llm, stt, tts }` — each component has `per_call` and `per_turn` values.
</ResponseField>

<ResponseField name="agents" type="array">
  Per-agent breakdown. Each item in the array contains the following fields alongside the same stats object described above.

  <Expandable title="agents item fields">
    <ResponseField name="id" type="string">
      The agent's unique identifier.
    </ResponseField>
    <ResponseField name="title" type="string">
      The agent's display name.
    </ResponseField>
    <ResponseField name="attempted" type="integer">
      Total calls started for this agent.
    </ResponseField>
    <ResponseField name="completed" type="integer">
      Calls completed or screened out for this agent.
    </ResponseField>
    <ResponseField name="screened_out" type="integer">
      Calls screened out for this agent.
    </ResponseField>
    <ResponseField name="completion_rate" type="number">
      Completion rate for this agent.
    </ResponseField>
    <ResponseField name="avg_duration_secs" type="object">
      Average call duration for this agent. Shape: `{ value, ci95, sample_count }`.
    </ResponseField>
    <ResponseField name="avg_ack_latency_secs" type="object">
      Average acknowledgement latency for this agent.
    </ResponseField>
    <ResponseField name="avg_ack_to_reply_secs" type="object">
      Average ack-to-reply time for this agent.
    </ResponseField>
    <ResponseField name="cost" type="object">
      Cost breakdown for this agent.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash curl
curl -G https://YOUR-FORMBHARO-SERVER/api/v1/workspaces/ws_xyz789/analytics \
  --data-urlencode "since=1700000000" \
  --data-urlencode "until=1700086400" \
  -H "Authorization: Bearer fb_live_0123456789ab_..."
```

<Note>
  The `completed` field in both the top-level response and each agent item includes `screened_out` calls. Subtract `screened_out` from `completed` to get the count of calls that went all the way through.
</Note>
