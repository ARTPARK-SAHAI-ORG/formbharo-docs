You need an API key. See [API Keys](/getting-started/api-keys).

<Steps>
  <Step title="Set your API key">
    ```bash
    export FORMBHARO_KEY="fb_live_0123456789ab_REPLACE_THIS_WITH_YOUR_KEY"
    ```
  </Step>

  <Step title="Create an agent">
    `POST` always creates a draft.

    <CodeGroup>
    ```bash curl
    curl -X POST "https://api.formbharo.artpark.ai/api/v1/agents" \
      -H "Authorization: Bearer $FORMBHARO_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "title": "Clinic intake",
        "questions": [
          { "question": "What is your full name?", "response_type": "string" },
          { "question": "What is your date of birth?", "response_type": "date" }
        ]
      }'
    ```

    ```python Python
    import os
    import requests

    body = {
        "title": "Clinic intake",
        "questions": [
            {"question": "What is your full name?", "response_type": "string"},
            {"question": "What is your date of birth?", "response_type": "date"},
        ],
    }
    response = requests.post(
        "https://api.formbharo.artpark.ai/api/v1/agents",
        headers={"Authorization": f"Bearer {os.environ['FORMBHARO_KEY']}"},
        json=body,
    )
    response.raise_for_status()
    agent_id = response.json()["id"]
    ```
    </CodeGroup>

    Save the `id` from the response.
  </Step>

  <Step title="Publish it">
    `PUT` always publishes. Send the same body again.

    ```bash curl
    curl -X PUT "https://api.formbharo.artpark.ai/api/v1/agents/AGENT_ID" \
      -H "Authorization: Bearer $FORMBHARO_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "title": "Clinic intake",
        "questions": [
          { "question": "What is your full name?", "response_type": "string" },
          { "question": "What is your date of birth?", "response_type": "date" }
        ]
      }'
    ```
  </Step>

  <Step title="Call it">
    Open the agent's call page and talk to it.

    ```
    https://formbharo.artpark.ai/agents/AGENT_ID
    ```

    Anyone with the link can fill the form by voice, no account needed. To run the call inside your own page instead, see [Run a Call](/guides/run-a-call).
  </Step>

  <Step title="Read its analytics">
    ```bash
    curl "https://api.formbharo.artpark.ai/api/v1/agents/AGENT_ID/analytics" \
      -H "Authorization: Bearer $FORMBHARO_KEY"
    ```

    Completion rate, call duration, and cost.
  </Step>
</Steps>
