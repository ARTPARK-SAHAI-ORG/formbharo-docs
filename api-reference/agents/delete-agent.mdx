`DELETE /api/v1/agents/{agent_id}` soft-deletes an agent. It disappears from all listings and cannot be retrieved via the API, but its calls and their collected answers remain accessible through the Calls endpoints. This operation cannot be undone.

**Authentication:** Required — include `Authorization: Bearer <api-key>` on every request.

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent to delete.
</ParamField>

<Warning>
  Deletion is permanent. The agent's configuration and version history are removed. Call records and collected answers are **not** deleted and remain queryable by `agent_id`, but you will not be able to recover or re-deploy this agent.
</Warning>

## Response

A successful deletion returns a confirmation object:

<ResponseField name="deleted" type="boolean">
  Always `true` on success.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the deleted agent.
</ResponseField>

## Example

<CodeGroup>
  ```bash curl
  curl -X DELETE https://form-fill-agent-backend.artpark.ai/api/v1/agents/agt_abc123 \
    -H "Authorization: Bearer fb_live_0123456789ab_..."
  ```
</CodeGroup>

### Example Response

```json
{
  "deleted": true,
  "id": "agt_abc123"
}
```
