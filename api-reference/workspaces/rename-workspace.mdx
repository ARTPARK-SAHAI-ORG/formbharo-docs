`PUT /api/v1/workspaces/{workspace_id}` renames a workspace. Only workspace admins can rename a workspace.

## Authentication

Required. The API key must belong to a workspace admin. Workspace members receive a `403 Forbidden` response.

```http
Authorization: Bearer <api-key>
```

## Path Parameters

<ParamField path="workspace_id" type="string" required>
  The unique identifier of the workspace to rename.
</ParamField>

## Request Body

<ParamField body="name" type="string" required>
  The new display name for the workspace. Must be a non-empty string.
</ParamField>

## Response

Returns the updated workspace object with the new name applied.

<ResponseField name="id" type="string">
  The workspace's unique identifier.
</ResponseField>

<ResponseField name="name" type="string">
  The updated display name of the workspace.
</ResponseField>

## Example

<CodeGroup>

```bash curl
curl -X PUT https://YOUR-FORMBHARO-SERVER/api/v1/workspaces/ws_xyz789 \
  -H "Authorization: Bearer fb_live_0123456789ab_..." \
  -H "Content-Type: application/json" \
  -d '{"name": "Acme Growth Team"}'
```

```python python
import requests

BASE_URL     = "https://YOUR-FORMBHARO-SERVER"
API_KEY      = "fb_live_0123456789ab_..."
WORKSPACE_ID = "ws_xyz789"

resp = requests.put(
    f"{BASE_URL}/api/v1/workspaces/{WORKSPACE_ID}",
    json={"name": "Acme Growth Team"},
    headers={"Authorization": f"Bearer {API_KEY}"},
)
resp.raise_for_status()
workspace = resp.json()

print(f"Renamed workspace to: {workspace['name']}")
```

</CodeGroup>

<Warning>
  Renaming a workspace is immediately visible to all members. Verify the new name before sending the request — there is no confirmation step.
</Warning>
