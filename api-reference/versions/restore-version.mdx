---
title: "Roll Back an Agent to a Previous Published Version"
sidebarTitle: "Restore Version"
description: "POST /api/v1/agents/{agent_id}/versions/{version}/restore rolls back an agent to an older published version, creating a new version record."
---

`POST /api/v1/agents/{agent_id}/versions/{version}/restore` rolls an agent back to a previous published version. The restore creates a new version record — it does not overwrite history. After a successful restore, the agent's live configuration matches the specified historical version and a new version number is assigned to that state.

## Authentication

This endpoint requires a valid API key in the `Authorization` header.

```http
Authorization: Bearer <api-key>
```

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent to restore.
</ParamField>

<ParamField path="version" type="integer" required>
  The version number to restore from. The agent's configuration will be set to match this version exactly.
</ParamField>

## Response

Returns a confirmation object with the newly assigned version number.

<ResponseField name="agent_id" type="string">
  The ID of the agent that was restored.
</ResponseField>

<ResponseField name="restored_from_version" type="integer">
  The historical version number that was used as the restore source.
</ResponseField>

<ResponseField name="new_version" type="integer">
  The version number assigned to the restored state. This is the version the agent is now live on.
</ResponseField>

<ResponseField name="restored_at" type="number">
  Unix timestamp (seconds) of when the restore was performed.
</ResponseField>

## Example

<CodeGroup>
```bash curl
curl -X POST \
  https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/versions/2/restore \
  -H "Authorization: Bearer fb_live_0123456789ab_..."
```

```python python
import requests

response = requests.post(
    "https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/versions/2/restore",
    headers={"Authorization": "Bearer fb_live_0123456789ab_..."},
)
result = response.json()
print(f"Restored from v{result['restored_from_version']} → now at v{result['new_version']}")
```
</CodeGroup>

### Sample Response

```json
{
  "agent_id": "agt_abc123",
  "restored_from_version": 2,
  "new_version": 5,
  "restored_at": 1718300000
}
```

<Warning>
  Restoring a version immediately updates the live agent. Any calls started after the restore will use the restored configuration. In-progress calls are not affected.
</Warning>

<Note>
  Version history is append-only. Restoring version 2 when you are on version 4 creates version 5 — versions 3 and 4 remain accessible in the version list.
</Note>
