An [Agent Skill](https://agentskills.io) is a folder of instructions that teaches a coding agent how to do one specific job. FormBharo publishes one: `formbharo`.

## Install

<CodeGroup>
```bash Claude Code
npx skills add ARTPARK-SAHAI-ORG/formbharo-skills --agent claude-code -g
```

```bash Cursor
npx skills add ARTPARK-SAHAI-ORG/formbharo-skills --agent cursor
```

```bash Windsurf
npx skills add ARTPARK-SAHAI-ORG/formbharo-skills --agent windsurf
```

```bash Codex
npx skills add ARTPARK-SAHAI-ORG/formbharo-skills --agent codex
```
</CodeGroup>

Restart your coding agent session after installing so it picks up the skill.

The repo is public ([ARTPARK-SAHAI-ORG/formbharo-skills](https://github.com/ARTPARK-SAHAI-ORG/formbharo-skills)), so no credentials are needed to install it.

### Manual install

```bash
git clone https://github.com/ARTPARK-SAHAI-ORG/formbharo-skills.git
cp -r formbharo-skills/skills/formbharo ~/.claude/skills/formbharo
```

For other tools, copy into their skills folder instead (Cursor: `.cursor/skills/`). Copy the whole `formbharo` folder, not just `SKILL.md` — `SKILL.md` links to files in its `references/` folder.

## Before you use it

The skill needs two environment variables. These are the skill's own names, not the rest of this site's convention:

| Variable | What it is |
|---|---|
| `FORMBHARO_API_KEY` | Create one in the web app under **Settings → API keys**. Starts with `fb_live_`, shown once. |
| `FORMBHARO_API_URL` | The address of your FormBharo API. This is not the web app's address. |

Verify both are set correctly:

```bash
curl -s -H "Authorization: Bearer $FORMBHARO_API_KEY" "$FORMBHARO_API_URL/api/v1/agents"
```

A list back (even an empty `[]`) means it's set up correctly.

## What it can do

Ask your coding agent to build, edit, or inspect a voice form agent in plain English. For building an agent, it follows these steps:

<Steps>
  <Step title="You describe the form">
    For example: "collect name, age, and whether they have a fever, in Hindi."
  </Step>
  <Step title="It builds the config">
    Each item becomes a question entry in the agent's JSON config.
  </Step>
  <Step title="It creates a draft">
    `POST /api/v1/agents`.
  </Step>
  <Step title="It publishes it">
    `PUT /api/v1/agents/{agent_id}` with the same body. This also saves it as version 1.
  </Step>
  <Step title="It verifies">
    `GET /api/v1/agents/{agent_id}` to confirm the agent looks right.
  </Step>
</Steps>

It can also edit an existing agent, pull the answers people gave on calls, and read back numbers and analytics without misleading you.

The skill only works from a plain-English description of your form, not a PDF or document directly. To turn a form document into an agent, see [PDF to form](/guides/pdf-to-form), which pairs Claude's own document reading with this skill.
