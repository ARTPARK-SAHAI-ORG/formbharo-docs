`GET /api/v1/agents/{agent_id}` returns the complete stored configuration for an agent. Use this to inspect exactly what the agent will say and ask, or to read a configuration before writing it elsewhere.

**Authentication:** Required — include `Authorization: Bearer <api-key>` on every request.

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent to retrieve.
</ParamField>

## Response

The response is the agent's full stored configuration object. Note that the **field names in the read-back response differ from the field names you use when creating or updating an agent**. The table below shows the mapping:

| Create / Update field | Read-back field | Description |
|---|---|---|
| `question` | `label` | The question text the agent says aloud |
| `response_type` | `type` | The expected data type of the answer |
| `description` | `context` | Background context provided to the AI |
| `ai_instructions` | `instructions` | Behavioural instructions for the AI |

<Warning>
  If you read back a configuration and then send it to `PUT /api/v1/agents/{agent_id}` or `POST /api/v1/agents`, the request will fail because the field names do not match. Use `PUT /api/v1/agents/{agent_id}/config` to write using stored field names directly, or translate the fields manually.
</Warning>

### Response Fields

<ResponseField name="id" type="string">
  The agent's unique identifier.
</ResponseField>

<ResponseField name="title" type="string">
  The agent's display name.
</ResponseField>

<ResponseField name="status" type="string">
  `draft` or `published`.
</ResponseField>

<ResponseField name="version" type="integer">
  The current published version number.
</ResponseField>

<ResponseField name="workspace_id" type="string">
  The workspace this agent belongs to.
</ResponseField>

<ResponseField name="agent_speaks_first" type="boolean">
  Whether the agent opens the call with an introduction.
</ResponseField>

<ResponseField name="language" type="string">
  BCP-47 language tag for the agent's voice.
</ResponseField>

<ResponseField name="questions" type="array">
  Ordered list of question objects, each containing `name`, `label`, `type`, `context`, `instructions`, and optionally `options`.
</ResponseField>

<ResponseField name="updated_at" type="number">
  Unix timestamp of the last configuration update.
</ResponseField>

## Example

<CodeGroup>
  ```bash curl
  curl https://form-fill-agent-backend.artpark.ai/api/v1/agents/agt_abc123 \
    -H "Authorization: Bearer fb_live_0123456789ab_..."
  ```
</CodeGroup>
