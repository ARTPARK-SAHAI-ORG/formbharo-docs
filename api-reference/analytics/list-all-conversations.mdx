`GET /api/v1/conversations` returns calls across all agents visible to your key. Unlike the per-agent conversations endpoint, this one always returns the paginated object shape regardless of whether you pass `limit` or `cursor`.

## Authentication

Required. Include your API key in the `Authorization` header.

```http
Authorization: Bearer <api-key>
```

## Query Parameters

<ParamField query="workspace_id" type="string">
  Filter results to a single workspace. Omit to return conversations across all workspaces your key can access.
</ParamField>

<ParamField query="agent_id" type="string">
  Filter results to a single agent.
</ParamField>

<ParamField query="status" type="string">
  Filter by conversation status. One of `in_progress`, `complete`, `screened_out`, or `failed`.
</ParamField>

<ParamField query="source" type="string">
  Filter by call source. Matches the `source` value recorded when the conversation was initiated.
</ParamField>

<ParamField query="since" type="number">
  Unix timestamp (inclusive). Returns only conversations whose `created_at` is greater than or equal to this value. Use this when polling for updates since your last sync.
</ParamField>

<ParamField query="until" type="number">
  Unix timestamp (inclusive). Returns only conversations whose `created_at` is less than or equal to this value.
</ParamField>

<ParamField query="limit" type="integer">
  Number of results per page. Must be between 1 and 200. Defaults to `50`.
</ParamField>

<ParamField query="cursor" type="integer">
  Pagination offset returned as `next_cursor` in the previous response. Omit to start from the beginning.
</ParamField>

## Response

The response always uses the paginated envelope shape.

```json
{
  "data": [ /* ConversationSummary[] */ ],
  "next_cursor": 50
}
```

`next_cursor` is `null` when there are no further pages.

### ConversationSummary fields

<ResponseField name="conversation_id" type="string">
  Unique identifier for the conversation. Use this to deduplicate records across polls.
</ResponseField>

<ResponseField name="agent_id" type="string">
  The agent that conducted this conversation.
</ResponseField>

<ResponseField name="status" type="string">
  Current status of the conversation: `in_progress`, `complete`, `screened_out`, or `failed`.
</ResponseField>

<ResponseField name="form_data" type="object">
  Key-value map of question keys to collected answers. Keys match the question identifiers defined on the agent.
</ResponseField>

<ResponseField name="form_status" type="string">
  Indicates whether form collection is still in progress or has finished.
</ResponseField>

<ResponseField name="created_at" type="number">
  Unix timestamp of the last write to this conversation record, not the call start time. See note below.
</ResponseField>

<ResponseField name="duration_secs" type="number">
  Total duration of the call in seconds. `null` for conversations still in progress.
</ResponseField>

## Polling Example

Use the `since` parameter to fetch only conversations updated after your last sync. Store the current timestamp before each request, then pass it as `since` on the next poll.

<CodeGroup>

```bash curl
# First poll — fetch all conversations in the last hour
SINCE=$(date -d '1 hour ago' +%s)

curl -G https://form-fill-agent-backend.artpark.ai/api/v1/conversations \
  --data-urlencode "since=$SINCE" \
  --data-urlencode "limit=200" \
  -H "Authorization: Bearer fb_live_0123456789ab_..."
```

```python python
import time
import requests

BASE_URL = "https://form-fill-agent-backend.artpark.ai"
API_KEY  = "fb_live_0123456789ab_..."

def poll_conversations(since: float) -> list[dict]:
    """Return all conversations updated at or after `since` (unix timestamp)."""
    results = []
    cursor  = None

    while True:
        params = {"since": since, "limit": 200}
        if cursor is not None:
            params["cursor"] = cursor

        resp = requests.get(
            f"{BASE_URL}/api/v1/conversations",
            params=params,
            headers={"Authorization": f"Bearer {API_KEY}"},
        )
        resp.raise_for_status()
        body = resp.json()

        results.extend(body["data"])
        cursor = body.get("next_cursor")
        if cursor is None:
            break

    return results


# Usage: seed `last_sync` from your datastore; update it after each successful poll.
last_sync = time.time() - 3600   # start: one hour ago
conversations = poll_conversations(since=last_sync)
print(f"Fetched {len(conversations)} conversation(s)")
```

</CodeGroup>

<Note>
  `created_at` is the last-write time of the conversation record, not the call start time. When polling, always use `conversation_id` to deduplicate records — a conversation that is still in progress may appear in multiple polls with an updated `created_at`.
</Note>
