`GET /api/v1/agents` returns all agents your API key can see, ordered newest first. Omit the pagination parameters to receive a plain JSON array. Pass `limit` and `cursor` together to paginate through large agent lists.

**Authentication:** Required — include `Authorization: Bearer <api-key>` on every request.

## Query Parameters

<ParamField query="limit" type="integer">
  The maximum number of agents to return in a single response. Providing this parameter switches the response shape to a paginated envelope containing a `data` array and a `next_cursor` value.
</ParamField>

<ParamField query="cursor" type="integer">
  The pagination offset. Pass the `next_cursor` value from the previous response to fetch the next page. Has no effect if `limit` is omitted.
</ParamField>

## Response

<Tabs>
  <Tab title="Without pagination">
    When you omit `limit`, the endpoint returns a plain JSON array of AgentListItem objects.

    ```json

        "id": "agt_abc123",
        "title": "Customer Onboarding Survey",
        "question_count": 8,
        "updated_at": 1714000000,
        "conversation_count": 142,
        "status": "published",
        "workspace_id": "ws_xyz789",
        "workspace_role": "admin"
      },
      {
        "id": "agt_def456",
        "title": "Post-Sale Follow-Up",
        "question_count": 5,
        "updated_at": 1713900000,
        "conversation_count": 37,
        "status": "draft",
        "workspace_id": "ws_xyz789",
        "workspace_role": "admin"
      }
    ]
    ```
  </Tab>
  <Tab title="With pagination">
    When you supply `limit`, the endpoint wraps the results in an envelope with a `next_cursor` field. Pass `next_cursor` as the `cursor` query parameter on the next request. A `null` value means you have reached the last page.

    ```json
    {
      "data": [
        {
          "id": "agt_abc123",
          "title": "Customer Onboarding Survey",
          "question_count": 8,
          "updated_at": 1714000000,
          "conversation_count": 142,
          "status": "published",
          "workspace_id": "ws_xyz789",
          "workspace_role": "admin"
        }
      ],
      "next_cursor": 50
    }
    ```
  </Tab>
</Tabs>

### AgentListItem Fields

<ResponseField name="id" type="string">
  The unique identifier for the agent.
</ResponseField>

<ResponseField name="title" type="string">
  The human-readable name of the agent, as set when it was created or last updated.
</ResponseField>

<ResponseField name="question_count" type="integer">
  The number of questions currently configured on the agent.
</ResponseField>

<ResponseField name="updated_at" type="number">
  Unix timestamp (seconds) of the last configuration update.
</ResponseField>

<ResponseField name="conversation_count" type="integer">
  Total number of calls initiated against this agent.
</ResponseField>

<ResponseField name="status" type="string">
  Either `draft` (never published or only saved locally) or `published` (live and callable).
</ResponseField>

<ResponseField name="workspace_id" type="string">
  The ID of the workspace this agent belongs to.
</ResponseField>

<ResponseField name="workspace_role" type="string">
  Your role in the agent's workspace — for example `admin`, `member`, or `viewer`.
</ResponseField>

## Examples

<CodeGroup>
  ```bash curl
  # Fetch all agents (no pagination)
  curl https://YOUR-FORMBHARO-SERVER/api/v1/agents \
    -H "Authorization: Bearer fb_live_0123456789ab_..."

  # Fetch the first page of 20 agents
  curl "https://YOUR-FORMBHARO-SERVER/api/v1/agents?limit=20" \
    -H "Authorization: Bearer fb_live_0123456789ab_..."

  # Fetch the next page using a cursor
  curl "https://YOUR-FORMBHARO-SERVER/api/v1/agents?limit=20&cursor=20" \
    -H "Authorization: Bearer fb_live_0123456789ab_..."
  ```

  ```python Python
  import requests

  BASE = "https://YOUR-FORMBHARO-SERVER"
  HEADERS = {"Authorization": "Bearer fb_live_0123456789ab_..."}

  # Fetch all agents (no pagination)
  response = requests.get(f"{BASE}/api/v1/agents", headers=HEADERS)
  agents = response.json()
  print(agents)

  # Paginate through all agents
  cursor = None
  all_agents = []

  while True:
      params = {"limit": 20}
      if cursor is not None:
          params["cursor"] = cursor

      response = requests.get(f"{BASE}/api/v1/agents", headers=HEADERS, params=params)
      page = response.json()
      all_agents.extend(page["data"])

      cursor = page.get("next_cursor")
      if cursor is None:
          break

  print(f"Total agents: {len(all_agents)}")
  ```
</CodeGroup>
