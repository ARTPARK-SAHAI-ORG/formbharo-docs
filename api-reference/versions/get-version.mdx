`GET /api/v1/agents/{agent_id}/versions/{version}` returns a complete snapshot of an agent at a specific version, including the full question list, scripts, and settings as they were at save time. Use this to inspect historical configuration or to feed a restore decision before calling [Restore Version](/api-reference/versions/restore-version).

## Authentication

This endpoint requires a valid API key in the `Authorization` header.

```http
Authorization: Bearer <api-key>
```

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent.
</ParamField>

<ParamField path="version" type="integer" required>
  The version number to retrieve. Version numbers start at `1` for the first published save.
</ParamField>

## Response

Returns a single `AgentVersionSnapshot` object containing the complete agent configuration as it existed at save time.

<ResponseField name="version" type="integer">
  The version number of this snapshot.
</ResponseField>

<ResponseField name="saved_at" type="number">
  Unix timestamp (seconds) recording when this version was saved.
</ResponseField>

<ResponseField name="title" type="string">
  The agent's title at the time this version was saved.
</ResponseField>

<ResponseField name="questions" type="array">
  The full list of questions configured at this version. Each entry includes the question name, label, type, and any associated scripts or validation rules as they existed at save time.
</ResponseField>

<ResponseField name="settings" type="object">
  Agent-level settings (voice, language, call behaviour, etc.) recorded at save time.
</ResponseField>

<ResponseField name="script" type="string">
  The opening script the agent uses at the start of a call, as saved in this version.
</ResponseField>

## Example

<CodeGroup>
```bash curl
curl https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/versions/3 \
  -H "Authorization: Bearer fb_live_0123456789ab_..."
```

```python python
import requests

response = requests.get(
    "https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/versions/3",
    headers={"Authorization": "Bearer fb_live_0123456789ab_..."},
)
snapshot = response.json()
print(snapshot["title"], "—", len(snapshot["questions"]), "questions")
```
</CodeGroup>

```json
  "version": 3,
  "saved_at": 1718100000,
  "title": "Patient Intake Form",
  "script": "Hi, I'm calling on behalf of Riverside Clinic to collect some intake information before your appointment.",
  "questions": [
    {
      "name": "full_name",
      "label": "Full Name",
      "type": "text",
      "instructions": "Ask the caller for their full legal name."
    },
    {
      "name": "date_of_birth",
      "label": "Date of Birth",
      "type": "date",
      "instructions": "Ask the caller for their date of birth."
    }
  ],
  "settings": {
    "voice": "en-US-Neural2-F",
    "language": "en-US",
    "max_call_duration_secs": 300
  }
}
```

<Note>
  This endpoint returns the configuration exactly as it was saved. It does not reflect any unsaved draft edits on the current agent.
</Note>
