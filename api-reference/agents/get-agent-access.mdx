`GET /api/v1/agents/{agent_id}/access` returns the current access list for an agent — the emails of users who have been explicitly granted access. Use this to audit who can view or operate an agent before making changes with the corresponding `PUT` endpoint.

**Authentication:** Required — include `Authorization: Bearer <api-key>` on every request.

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent whose access list you want to retrieve.
</ParamField>

## Response

The response is an array of access entry objects.

<ResponseField name="email" type="string">
  The email address of the user with access.
</ResponseField>

<ResponseField name="role" type="string">
  The user's role on this agent — for example `admin`, `member`, or `viewer`.
</ResponseField>

<ResponseField name="granted_at" type="number">
  Unix timestamp of when access was granted.
</ResponseField>

<Info>
  Workspace-level members who have access to all agents in a workspace are **not** listed here. This endpoint only returns users who have been explicitly added to this specific agent's access list.
</Info>

## Example

<CodeGroup>
  ```bash curl
  curl https://form-fill-agent-backend.artpark.ai/api/v1/agents/agt_abc123/access \
    -H "Authorization: Bearer fb_live_0123456789ab_..."
  ```
</CodeGroup>
