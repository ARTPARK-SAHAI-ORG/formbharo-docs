`GET /api/v1/agents/{agent_id}/versions` returns a list of all published versions of an agent, ordered newest first. Drafts are not versioned; version 1 is the first published save. Each item in the response is a summary — use [Get Version](/api-reference/versions/get-version) to retrieve the full configuration for a specific version.

## Authentication

This endpoint requires a valid API key in the `Authorization` header.

```http
Authorization: Bearer <api-key>
```

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent whose version history you want to retrieve.
</ParamField>

## Response

Returns an array of `AgentVersionSummary` objects.

<ResponseField name="version" type="integer">
  The version number. Starts at `1` for the first published save and increments with each subsequent publish or restore.
</ResponseField>

<ResponseField name="saved_at" type="number">
  Unix timestamp (seconds) recording when this version was saved.
</ResponseField>

<ResponseField name="title" type="string">
  The agent's title at the time this version was saved.
</ResponseField>

<ResponseField name="question_count" type="integer">
  The number of questions configured in this version.
</ResponseField>

## Example

<CodeGroup>
```bash curl
curl https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/versions \
  -H "Authorization: Bearer fb_live_0123456789ab_..."
```

```python python
import requests

response = requests.get(
    "https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/versions",
    headers={"Authorization": "Bearer fb_live_0123456789ab_..."},
)
print(response.json())
```
</CodeGroup>
