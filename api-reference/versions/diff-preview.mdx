---
title: "Agent Diff Preview — Review Changes Before Publish"
sidebarTitle: "Diff Preview"
description: "POST /api/v1/agents/{agent_id}/diff-preview returns a diff of what would change if you saved the provided configuration, without actually saving it."
---

`POST /api/v1/agents/{agent_id}/diff-preview` accepts the same body as `PUT /api/v1/agents/{agent_id}` and returns a line-by-line diff of what would change. Nothing is saved. Use this to review changes before committing a publish — for example, to display a confirmation screen in your own UI or to run an automated check before deploying an update.

## Authentication

This endpoint requires a valid API key in the `Authorization` header.

```http
Authorization: Bearer <api-key>
```

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent you want to preview changes for.
</ParamField>

## Request Body

Send the full agent configuration using the same field names as `PUT /api/v1/agents/{agent_id}`. All fields are evaluated against the agent's current live (published) configuration to produce the diff.

<ParamField body="title" type="string">
  The agent's display name.
</ParamField>

<ParamField body="script" type="string">
  The opening script the agent reads at the start of a call.
</ParamField>

<ParamField body="questions" type="array">
  The full list of questions. Each question object should include `name`, `label`, `type`, and `instructions`.
</ParamField>

<ParamField body="settings" type="object">
  Agent-level settings such as voice, language, and call duration limits.
</ParamField>

## Response

<ResponseField name="lines" type="array">
  An ordered array of `DiffLine` objects — the same shape returned by [Version Diff](/api-reference/versions/get-version-diff).

  <Expandable title="DiffLine fields">
    <ResponseField name="type" type="string">
      The role of this line. One of `add`, `remove`, `context`, `hunk`, or `meta`.
    </ResponseField>
    <ResponseField name="content" type="string">
      The text content of the diff line.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash curl
curl -X POST \
  https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/diff-preview \
  -H "Authorization: Bearer fb_live_0123456789ab_..." \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Patient Intake Form",
    "script": "Hi, I am calling on behalf of Riverside Clinic.",
    "questions": [
      {
        "name": "full_name",
        "label": "Full Name",
        "type": "text",
        "instructions": "Ask the caller for their full legal name."
      },
      {
        "name": "date_of_birth",
        "label": "Date of Birth",
        "type": "date",
        "instructions": "Ask the caller for their date of birth."
      },
      {
        "name": "insurance_provider",
        "label": "Insurance Provider",
        "type": "text",
        "instructions": "Ask the caller for their insurance provider name."
      }
    ],
    "settings": {
      "voice": "en-US-Neural2-F",
      "language": "en-US",
      "max_call_duration_secs": 300
    }
  }'
```

```python python
import requests

payload = {
    "title": "Patient Intake Form",
    "script": "Hi, I am calling on behalf of Riverside Clinic.",
    "questions": [
        {
            "name": "full_name",
            "label": "Full Name",
            "type": "text",
            "instructions": "Ask the caller for their full legal name.",
        },
        {
            "name": "date_of_birth",
            "label": "Date of Birth",
            "type": "date",
            "instructions": "Ask the caller for their date of birth.",
        },
        {
            "name": "insurance_provider",
            "label": "Insurance Provider",
            "type": "text",
            "instructions": "Ask the caller for their insurance provider name.",
        },
    ],
    "settings": {
        "voice": "en-US-Neural2-F",
        "language": "en-US",
        "max_call_duration_secs": 300,
    },
}

response = requests.post(
    "https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/diff-preview",
    headers={
        "Authorization": "Bearer fb_live_0123456789ab_...",
        "Content-Type": "application/json",
    },
    json=payload,
)

for line in response.json()["lines"]:
    print(line["type"].ljust(8), line["content"])
```
</CodeGroup>

### Sample Response

```json
{
  "lines": [
    { "type": "meta",    "content": "--- current" },
    { "type": "meta",    "content": "+++ preview" },
    { "type": "hunk",    "content": "@@ -18,4 +18,8 @@" },
    { "type": "context", "content": "   \"name\": \"date_of_birth\"," },
    { "type": "context", "content": "   \"type\": \"date\"" },
    { "type": "add",     "content": "+  \"name\": \"insurance_provider\"," },
    { "type": "add",     "content": "+  \"label\": \"Insurance Provider\"," },
    { "type": "add",     "content": "+  \"type\": \"text\"," },
    { "type": "add",     "content": "+  \"instructions\": \"Ask the caller for their insurance provider name.\"" }
  ]
}
```

<Note>
  An empty `lines` array means your submitted configuration is identical to the current live version. No version would be created if you proceeded with the save.
</Note>

<Tip>
  If you prefer to submit the raw stored-format field names (`label`, `type`, `context`, `instructions`), use [Config Diff Preview](/api-reference/versions/config-diff-preview) instead.
</Tip>
