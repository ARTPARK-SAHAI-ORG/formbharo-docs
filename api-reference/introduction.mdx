Every endpoint sits under `/api/v1` on your FormBharo server. Set two shell variables and
the examples on these pages run as they are:

```bash
export FORMBHARO_KEY=fb_live_0123456789ab_REPLACE_THIS_WITH_THE_KEY_YOU_COPIED
export FORMBHARO_URL=https://YOUR-FORMBHARO-SERVER
```

Send the key on every request in the `Authorization` header, after the word `Bearer`.
Three routes take no key: see [API keys](/getting-started/api-keys).

## One endpoint that is not listed here

`POST /offer` opens the audio connection that starts a call. It sits at the bare path
rather than under `/api/v1`, so it is not in the schema behind these pages. See
[Run a call from your own page](/guides/run-a-call).
