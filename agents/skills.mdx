An [Agent Skill](https://agentskills.io) is a folder of instructions that teaches a coding agent how to do one specific job. FormBharo publishes two.

| Skill | What it does |
| --- | --- |
| `formbharo-start` | Walks you through your first agent: gets your API key, builds the agent, gives you a link to call it |
| `formbharo` | Builds and edits agents, pulls the answers people gave on calls, reads the analytics |

## Install

<CodeGroup>
```bash Claude Code
npx skills add ARTPARK-SAHAI-ORG/formbharo-skills --agent claude-code -g
```

```bash Cursor
npx skills add ARTPARK-SAHAI-ORG/formbharo-skills --agent cursor
```

```bash Windsurf
npx skills add ARTPARK-SAHAI-ORG/formbharo-skills --agent windsurf
```

```bash Codex
npx skills add ARTPARK-SAHAI-ORG/formbharo-skills --agent codex
```
</CodeGroup>

Restart your coding agent session after installing so it picks up the skills. The repo is public ([ARTPARK-SAHAI-ORG/formbharo-skills](https://github.com/ARTPARK-SAHAI-ORG/formbharo-skills)), so no credentials are needed.

## Start here

Call the first skill by name:

```
/formbharo-start
```

It asks what you want to find out on the call and in what language, builds and publishes the agent, and gives you a link you can ring up and try. It asks for your API key along the way and saves it, so you paste the key once.

After that first agent, say what you want in your own words: "add a question about age", "show me last week's calls", "put the answers in a spreadsheet".

### Manual install

```bash
git clone https://github.com/ARTPARK-SAHAI-ORG/formbharo-skills.git
cp -r formbharo-skills/skills/formbharo ~/.claude/skills/formbharo
cp -r formbharo-skills/skills/formbharo-start ~/.claude/skills/formbharo-start
```

Copy both folders whole, since `formbharo-start` links across to `formbharo`. Those paths are for Claude Code. Cursor reads `.cursor/skills/`, and Windsurf and Codex each have their own skills folder.

## The API key

Open the web app, click your profile picture in the top right, then **API keys**. The key starts with `fb_live_` and is shown once.

The first time a skill needs the key it asks you for it. Paste it in and it is saved to the `env` block of `~/.claude/settings.json`, so you are asked once.

To check a key yourself, put it in `FORMBHARO_API_KEY` and run:

```bash
curl -s -H "Authorization: Bearer $FORMBHARO_API_KEY" "https://api.formbharo.artpark.ai/api/v1/agents"
```

A list back, even an empty `[]`, means the key works.

## What they can do

Describe your form in plain English, for example "collect name, age, and whether they have a fever, in Hindi", and the skill builds and publishes the agent. You can also ask it to edit an existing agent, pull the answers people gave on calls, and read back analytics.

They work from a plain-English description only, not a PDF or document directly. To turn a form document into an agent, see [Create an agent from a PDF](/guides/pdf-to-form).
