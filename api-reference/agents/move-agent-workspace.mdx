---
title: "PUT /api/v1/agents/{agent_id}/workspace — Move Agent"
sidebarTitle: "Move Agent"
description: "PUT /api/v1/agents/{agent_id}/workspace moves an agent to a different workspace. You must be an admin in the target workspace."
---

`PUT /api/v1/agents/{agent_id}/workspace` moves an agent from its current workspace to another. You must have admin rights in the target workspace. The agent retains its configuration, version history, and call records after the move. Access lists tied to the old workspace may change — review them after moving.

**Authentication:** Required — include `Authorization: Bearer <api-key>` on every request.

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent to move.
</ParamField>

## Request Body

<ParamField body="workspace_id" type="string" required>
  The ID of the destination workspace. You must have admin rights in this workspace.
</ParamField>

<Warning>
  Moving an agent changes which workspace members can see and manage it. Users who had access through the old workspace will no longer see the agent unless they are also members of the new workspace or are listed in the agent's explicit access list.
</Warning>

## Response

<ResponseField name="agent_id" type="string">
  The ID of the moved agent.
</ResponseField>

<ResponseField name="workspace_id" type="string">
  The ID of the new workspace — confirms the agent has been moved successfully.
</ResponseField>

## Example

<CodeGroup>
  ```bash curl
  curl -X PUT https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/workspace \
    -H "Authorization: Bearer fb_live_0123456789ab_..." \
    -H "Content-Type: application/json" \
    -d '{
      "workspace_id": "ws_newworkspace123"
    }'
  ```
</CodeGroup>

### Example Response

```json
{
  "agent_id": "agt_abc123",
  "workspace_id": "ws_newworkspace123"
}
```
