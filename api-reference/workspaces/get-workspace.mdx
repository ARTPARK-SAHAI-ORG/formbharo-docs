`GET /api/v1/workspaces/{workspace_id}` returns details about a workspace, including its member list with roles.

## Authentication

Required. Include your API key in the `Authorization` header.

```http
Authorization: Bearer <api-key>
```

## Path Parameters

<ParamField path="workspace_id" type="string" required>
  The unique identifier of the workspace to retrieve. Obtain this from [GET /api/v1/workspaces](/api-reference/workspaces/list-workspaces).
</ParamField>

## Response

Returns a WorkspaceDetail object.

<ResponseField name="id" type="string">
  The workspace's unique identifier.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the workspace.
</ResponseField>

<ResponseField name="role" type="string">
  Your role in this workspace: `admin` or `member`.
</ResponseField>

<ResponseField name="members" type="array">
  The full list of members in this workspace. Each item contains the member's email address and their role.

  <Expandable title="members item fields">
    <ResponseField name="email" type="string">
      The member's email address.
    </ResponseField>
    <ResponseField name="role" type="string">
      The member's role: `admin` or `member`.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash curl
curl https://form-fill-agent-backend.artpark.ai/api/v1/workspaces/ws_xyz789 \
  -H "Authorization: Bearer fb_live_0123456789ab_..."
```

Example response:

```json
{
  "id": "ws_xyz789",
  "name": "Acme Sales Team",
  "role": "admin",
  "members": [
    { "email": "alice@acme.com", "role": "admin" },
    { "email": "bob@acme.com",   "role": "member" }
  ]
}
```
