`POST /api/v1/agents` creates a new agent as a draft. Send the full configuration in the request body — at minimum a `title` and a `questions` array. The agent will not be callable until you publish it with `PUT /api/v1/agents/{agent_id}`.

**Authentication:** Required — include `Authorization: Bearer <api-key>` on every request.

## Request Body

<ParamField body="title" type="string" required>
  The display name of the agent. Shown in dashboards and analytics reports.
</ParamField>

<ParamField body="questions" type="array" required>
  The ordered list of questions the agent will ask. Each entry is a question object — see the [Agent Configuration reference](/reference/agent-configuration) for the full set of fields available per question, including `question`, `response_type`, `description`, `ai_instructions`, and `options`.
</ParamField>

<ParamField body="workspace_id" type="string">
  The workspace to create the agent in. Defaults to your personal workspace if omitted.
</ParamField>

<ParamField body="agent_speaks_first" type="boolean">
  When `true`, the agent opens the call with an introduction before asking the first question. Defaults to `false`.
</ParamField>

<ParamField body="language" type="string">
  BCP-47 language tag for the agent's voice (for example `en-US`, `hi-IN`). Defaults to `en-US`.
</ParamField>

<Note>
  This endpoint creates the agent in **draft** status. To publish it and make it callable, issue a `PUT /api/v1/agents/{agent_id}` with the complete configuration.
</Note>

## Response

<ResponseField name="id" type="string">
  The unique identifier of the newly created agent. Store this — you will need it for all subsequent operations on this agent.
</ResponseField>

<ResponseField name="workspace_id" type="string">
  The workspace the agent was created in.
</ResponseField>

## Validation Errors

If the request body fails validation, the API returns `400 Bad Request` with a `validation_issues` array describing each problem:

```json
{
  "error": "Validation failed",
  "validation_issues": [
    {
      "field": "questions[0].response_type",
      "message": "response_type must be one of: text, number, date, select, multi_select"
    }
  ]
}
```

## Examples

<CodeGroup>
  ```bash curl
  curl -X POST https://form-fill-agent-backend.artpark.ai/api/v1/agents \
    -H "Authorization: Bearer fb_live_0123456789ab_..." \
    -H "Content-Type: application/json" \
    -d '{
      "title": "New Patient Registration",
      "questions": [
        {
          "question": "What is your full legal name?",
          "response_type": "text",
          "description": "We need your full name as it appears on your ID.",
          "ai_instructions": "Ask clearly and confirm spelling if the name is unusual."
        },
        {
          "question": "What is your date of birth?",
          "response_type": "date",
          "description": "Required for identity verification.",
          "ai_instructions": "Accept any common date format and confirm the year."
        }
      ],
      "agent_speaks_first": true
    }'
  ```

  ```python Python
  import requests

  BASE = "https://form-fill-agent-backend.artpark.ai"
  HEADERS = {
      "Authorization": "Bearer fb_live_0123456789ab_...",
      "Content-Type": "application/json",
  }

  payload = {
      "title": "New Patient Registration",
      "questions": [
          {
              "question": "What is your full legal name?",
              "response_type": "text",
              "description": "We need your full name as it appears on your ID.",
              "ai_instructions": "Ask clearly and confirm spelling if the name is unusual.",
          },
          {
              "question": "What is your date of birth?",
              "response_type": "date",
              "description": "Required for identity verification.",
              "ai_instructions": "Accept any common date format and confirm the year.",
          },
      ],
      "agent_speaks_first": True,
  }

  response = requests.post(f"{BASE}/api/v1/agents", headers=HEADERS, json=payload)
  result = response.json()

  print("New agent ID:", result["id"])
  print("Workspace:   ", result["workspace_id"])
  ```
</CodeGroup>
