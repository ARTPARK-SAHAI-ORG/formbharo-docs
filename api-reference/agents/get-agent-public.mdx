title: "GET /api/v1/agents/{agent_id}/public — Public Agent Info"
sidebarTitle: "Get Public Info"
description: "GET /api/v1/agents/{agent_id}/public returns the agent title, questions list, and agent_speaks_first flag without requiring an API key."
---

`GET /api/v1/agents/{agent_id}/public` returns the information your web page needs to draw a form before starting a call. It requires no API key, so it is safe to call from browser JavaScript. Use it to pre-populate form fields, display the agent's name, or decide whether to show an intro screen before connecting the call.

**Authentication:** Not required. This route is intentionally open.

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the published agent to look up.
</ParamField>

<Note>
  This endpoint only returns data for **published** agents. A draft agent returns a `404 Not Found` response.
</Note>

## Response

<ResponseField name="title" type="string">
  The agent's display name.
</ResponseField>

<ResponseField name="questions" type="array">
  The ordered list of questions the agent will ask. Each entry contains:

  <Expandable title="Question object fields">
    <ResponseField name="name" type="string">
      The machine-readable key used to store the collected answer.
    </ResponseField>
    <ResponseField name="label" type="string">
      The human-readable question text.
    </ResponseField>
    <ResponseField name="type" type="string">
      The expected answer type: `text`, `number`, `date`, `select`, or `multi_select`.
    </ResponseField>
    <ResponseField name="options" type="array">
      For `select` and `multi_select` types, the list of allowed answer values. Absent for other types.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="agent_speaks_first" type="boolean">
  When `true`, the agent opens the call with an introduction rather than immediately asking the first question.
</ResponseField>

## Examples

<CodeGroup>
  ```bash curl
  curl https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/public
  ```

  ```javascript JavaScript
  const agentId = "agt_abc123";
  const base = "https://YOUR-FORMBHARO-SERVER";

  const response = await fetch(`${base}/api/v1/agents/${agentId}/public`);
  const agent = await response.json();

  console.log("Agent title:", agent.title);
  console.log("Questions:", agent.questions.length);
  console.log("Agent speaks first:", agent.agent_speaks_first);

  // Render question labels into a form
  for (const question of agent.questions) {
    console.log(`  [${question.type}] ${question.label}`);
    if (question.options) {
      console.log("    Options:", question.options.join(", "));
    }
  }
  ```
</CodeGroup>
