`GET /api/v1/agents/{agent_id}/analytics` returns performance statistics for one agent, optionally filtered by time window, status, or call source.

## Authentication

Required. Include your API key in the `Authorization` header.

```http
Authorization: Bearer <api-key>
```

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent to retrieve analytics for.
</ParamField>

## Query Parameters

<ParamField query="status" type="string">
  Restrict the calculation to conversations with this status. One of `in_progress`, `complete`, `screened_out`, or `failed`.
</ParamField>

<ParamField query="source" type="string">
  Restrict the calculation to conversations from a specific call source.
</ParamField>

<ParamField query="since" type="number">
  Unix timestamp lower bound on `created_at` (inclusive). Only conversations created at or after this time are included.
</ParamField>

<ParamField query="until" type="number">
  Unix timestamp upper bound on `created_at` (inclusive). Only conversations created at or before this time are included.
</ParamField>

## Response

<ResponseField name="attempted" type="integer">
  Total number of calls started for this agent within the requested window.
</ResponseField>

<ResponseField name="completed" type="integer">
  Number of calls with status `complete` or `screened_out`. See warning below.
</ResponseField>

<ResponseField name="screened_out" type="integer">
  Number of calls where the contact was screened out before completing the full form.
</ResponseField>

<ResponseField name="completion_rate" type="number">
  Ratio of `completed` to `attempted`, expressed as a decimal between 0 and 1.
</ResponseField>

<ResponseField name="avg_duration_secs" type="object">
  Average call duration in seconds.

  <Expandable title="avg_duration_secs fields">
    <ResponseField name="value" type="number">
      The mean value across all sampled calls. `null` when there are no usable calls.
    </ResponseField>
    <ResponseField name="ci95" type="array">
      95% confidence interval as `[lower, upper]`. `null` when fewer than 2 calls are available.
    </ResponseField>
    <ResponseField name="sample_count" type="integer">
      Number of calls included in the calculation.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="avg_ack_latency_secs" type="object">
  Average time from call connection to the agent's first acknowledgement, in seconds. Same shape as `avg_duration_secs`.

  <Expandable title="avg_ack_latency_secs fields">
    <ResponseField name="value" type="number">
      The mean value. `null` when there are no usable calls.
    </ResponseField>
    <ResponseField name="ci95" type="array">
      95% confidence interval as `[lower, upper]`. `null` when fewer than 2 calls are available.
    </ResponseField>
    <ResponseField name="sample_count" type="integer">
      Number of calls included in the calculation.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="avg_ack_to_reply_secs" type="object">
  Average time from the agent's acknowledgement to the contact's first reply, in seconds. Same shape as `avg_duration_secs`.

  <Expandable title="avg_ack_to_reply_secs fields">
    <ResponseField name="value" type="number">
      The mean value. `null` when there are no usable calls.
    </ResponseField>
    <ResponseField name="ci95" type="array">
      95% confidence interval as `[lower, upper]`. `null` when fewer than 2 calls are available.
    </ResponseField>
    <ResponseField name="sample_count" type="integer">
      Number of calls included in the calculation.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cost" type="object">
  Cost breakdown for the agent within the requested window.

  <Expandable title="cost fields">
    <ResponseField name="call_count" type="integer">
      Number of calls included in the cost calculation.
    </ResponseField>
    <ResponseField name="total" type="object">
      Total cost across all components. Contains `per_call` and `per_turn` values.
    </ResponseField>
    <ResponseField name="llm" type="object">
      LLM inference cost. Contains `per_call` and `per_turn` values.
    </ResponseField>
    <ResponseField name="stt" type="object">
      Speech-to-text cost. Contains `per_call` and `per_turn` values.
    </ResponseField>
    <ResponseField name="tts" type="object">
      Text-to-speech cost. Contains `per_call` and `per_turn` values.
    </ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  `completed` includes `screened_out`. Subtract `screened_out` from `completed` for calls that went all the way through.
</Warning>

## Example

<CodeGroup>

```bash curl
curl -G https://form-fill-agent-backend.artpark.ai/api/v1/agents/agt_abc123/analytics \
  --data-urlencode "since=1700000000" \
  --data-urlencode "until=1700086400" \
  -H "Authorization: Bearer fb_live_0123456789ab_..."
```

```python python
import requests

BASE_URL = "https://form-fill-agent-backend.artpark.ai"
API_KEY  = "fb_live_0123456789ab_..."
AGENT_ID = "agt_abc123"

resp = requests.get(
    f"{BASE_URL}/api/v1/agents/{AGENT_ID}/analytics",
    params={
        "since": 1700000000,
        "until": 1700086400,
    },
    headers={"Authorization": f"Bearer {API_KEY}"},
)
resp.raise_for_status()
analytics = resp.json()

attempted    = analytics["attempted"]
completed    = analytics["completed"]
screened_out = analytics["screened_out"]
full_through = completed - screened_out

print(f"Attempted:           {attempted}")
print(f"Fully completed:     {full_through}")
print(f"Screened out:        {screened_out}")
print(f"Completion rate:     {analytics['completion_rate']:.1%}")
print(f"Avg duration (s):    {analytics['avg_duration_secs']['value']}")
print(f"Total cost/call:     {analytics['cost']['total']['per_call']}")
```

</CodeGroup>
