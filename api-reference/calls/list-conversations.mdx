---

`GET /api/v1/agents/{agent_id}/conversations` returns all calls for a specific agent, newest first. By default, each record includes the full transcript — pass `include_transcript=false` to exclude it for faster responses when you only need form data or status information.

## Authentication

This endpoint requires a valid API key in the `Authorization` header.

```http
Authorization: Bearer <api-key>
```

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent whose calls you want to list.
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer">
  Maximum number of records to return per page. When omitted, all records are returned as a plain array. When provided, the response is a paginated envelope object.
</ParamField>

<ParamField query="cursor" type="integer">
  Pagination offset. Pass the value of `next_cursor` from the previous response to fetch the next page. Only meaningful when `limit` is also set.
</ParamField>

<ParamField query="since" type="number">
  Unix timestamp (seconds). Only return calls with a `created_at` value at or after this time.
</ParamField>

<ParamField query="until" type="number">
  Unix timestamp (seconds). Only return calls with a `created_at` value at or before this time.
</ParamField>

<ParamField query="status" type="string">
  Filter results to calls matching this status string (e.g. `completed`, `failed`, `in_progress`).
</ParamField>

<ParamField query="source" type="string">
  Filter results to calls matching this source string (e.g. `outbound`, `web`).
</ParamField>

<ParamField query="include_transcript" type="boolean" default="true">
  Set to `false` to exclude transcript data from each record. Omitting transcripts significantly reduces response size when you only need form data or metadata. When `include_transcript=false`, the `transcript` key is absent from each record entirely — it is not present with an empty value.
</ParamField>

## Response

The response shape depends on whether you pass pagination parameters:

- **Without `limit`** — returns a plain JSON array of conversation objects.
- **With `limit`** — returns a paginated envelope: `{ "data": [...], "next_cursor": <integer | null> }`. A `null` `next_cursor` means you have reached the last page.

Each conversation object includes the following key fields:

<ResponseField name="conversation_id" type="string">
  The unique identifier for this call.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the call (e.g. `completed`, `failed`, `in_progress`).
</ResponseField>

<ResponseField name="form_data" type="object">
  Key/value pairs mapping question names to the answers collected during the call.
</ResponseField>

<ResponseField name="form_status" type="object">
  Per-field status information indicating whether each field was `filled`, `skipped`, or `pending`.
</ResponseField>

<ResponseField name="filled_fields" type="integer">
  The number of questions that have been answered.
</ResponseField>

<ResponseField name="total_fields" type="integer">
  The total number of questions in the agent at the time of the call.
</ResponseField>

<ResponseField name="created_at" type="number">
  Unix timestamp (seconds) of when the call was initiated.
</ResponseField>

<ResponseField name="duration_secs" type="number">
  The total duration of the call in seconds. `null` if the call has not yet ended.
</ResponseField>

## Example

<CodeGroup>
```bash curl
curl "https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/conversations?include_transcript=false&limit=20" \
  -H "Authorization: Bearer fb_live_0123456789ab_..."
```

```python python
import requests

params = {
    "include_transcript": "false",
    "limit": 20,
}

response = requests.get(
    "https://YOUR-FORMBHARO-SERVER/api/v1/agents/agt_abc123/conversations",
    headers={"Authorization": "Bearer fb_live_0123456789ab_..."},
    params=params,
)
page = response.json()
calls = page["data"]
next_cursor = page.get("next_cursor")

print(f"Fetched {len(calls)} calls. Next cursor: {next_cursor}")
```
